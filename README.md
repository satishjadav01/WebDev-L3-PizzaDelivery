# 🍕 Pizza Delivery Management System

A modern and user-friendly **Pizza Delivery Management System** designed to simplify online food ordering and restaurant operations. Customers can explore pizzas, manage their cart, place orders, and track their deliveries.

## 🚀 Features

- **User Authentication** – Secure user registration and login.
- **Pizza Menu** – Browse pizzas with images, descriptions, and prices.
- **Shopping Cart** – Add, remove, and manage cart items.
- **Order Management** – Place and manage food orders.
- **Online Payments** – Integrated payment functionality.
- **Order Tracking** – Track order status.
- **Admin Dashboard** – Manage pizzas, customers, and orders.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- React.js
- TypeScript
- TanStack Start
- Tailwind CSS
- Node.js
- npm

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/satishjadav01/pizza-delivery-management-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd pizza-delivery-management-system
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
